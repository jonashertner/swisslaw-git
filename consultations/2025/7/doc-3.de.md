# Verordnung über die Bearbeitung biometrischer erkennungsdienstlicher Daten

Änderung vom ...

I Die Verordnung vom 6. Dezember 2013[^t-1] über die Bearbeitung biometrischer erkennungsdienstlicher Daten wird wie folgt geändert:

[^t-1]: SR 361.3

**Abs. 1 Bst. d**

- d. die Fingerabdrücke und Gesichtsbilder, die gestützt auf die Asylgesetzgebung Asylsuchenden abgenommen oder von ihnen erstellt wurden;
