# Verfügung des Volkswirtschaftsdepartementes über den Katalog der kantonalen Merkmale im Einwohnerregister

Vom 11.09.2013 (Stand 01.10.2013)

Das Volkswirtschaftsdepartement,

gestützt auf Art. 88 Abs. 3 des Gemeindegesetzes vom 17. August 1998,

beschliesst:

#### § 1

<sup>1</sup> Die kantonalen Merkmale werden wie folgt umschrieben, wobei der Zugriff auf ein Merkmal zum Zugriff auf die Teilmerkmale respektive Ausprägungen berechtigt:

<table>
<tr><th>lit.</th><th>Merkmal</th><th>Teilmerkmal respektive Ausprägung</th><th>Codierung</th></tr>
<tr><td>a)</td><td>anderer Vor- und Nachname</td><td>lediger Name / Allianzname / Name in ausländischem Pass / anderer Name / Rufname</td><td>Schreibweise gemäss amtlichem Katalog des Bundesamtes für Statistik</td></tr>
<tr><td>b)</td><td>Name und Vorname der Eltern</td><td>Name und Vorname der Mutter / Name und Vorname des Vaters</td><td>Schreibweise gemäss amtlichem Katalog des Bundesamtes für Statistik</td></tr>
<tr><td>c)</td><td>Beschränkung der Handlungsfähigkeit</td><td>Handlungsfähigkeit beschränkt / Handlungsfähigkeit nicht beschränkt</td><td>Handlungsfähigkeit beschränkt = 1 / Handlungsfähigkeit nicht beschränkt = 2</td></tr>
<tr><td>d)</td><td>gesetzliche Vertretung mit Zustelladresse</td><td>Name und Vorname / Wohn- bzw. Zustelladresse des gesetzlichen Vertreters</td><td>Schreibweise gemäss amtlichem Katalog des Bundesamtes für Statistik</td></tr>
<tr><td>e)</td><td>Krankenversicherung</td><td>grundversichert / nicht grundversichert</td><td>grundversichert = 1 / nicht grundversichert = 2</td></tr>
<tr><td>f)</td><td>Feuerwehrpflicht</td><td>pflichtig / nicht pflichtig</td><td>pflichtig = 1 / nicht pflichtig = 2</td></tr>
<tr><td>g)</td><td>Haushalt- und/oder Familiennummer</td><td></td><td>Nummer</td></tr>
<tr><td>h)</td><td>Nummer im Ausländerregister</td><td>ZAR-Nummer / ZEMIS-Nummer</td><td>Nummer</td></tr>
<tr><td>i)</td><td>Beruf und Art der Erwerbstätigkeit</td><td>Beruf / erwerbslos / selbständig / unselbständig / AHV/IV-Bezüger / Nichterwerbsperson</td><td>Beruf = Text / erwerbslos = 0 / selbständig = 1 / unselbständig = 2 / AHV/IV-Bezüger = 3 / Nichterwerbsperson = 4</td></tr>
</table>

#### § 2
