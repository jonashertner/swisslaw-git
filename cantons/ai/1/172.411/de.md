# Standeskommissionsbeschluss über die Kantonale Versicherungskasse

Gesetzessammlung Appenzell I. Rh. – Januar 2014

vom 3. September 2013

Die Standeskommission des Kantons Appenzell I.Rh., gestützt auf Art. 9 Abs. 2 der Verordnung über die Kantonale Versicherungskasse vom 24. Juni 2013, beschliesst:

#### Art. 1

<sup>1</sup> Die Sparbeiträge betragen in Prozenten des versicherten Jahreslohns: Alter Sparbeitrag Arbeitgeber Sparbeitrag Arbeitnehmer (Jahre) 20-22 0 % 23-29 4.0 % 30-34 6.5 % 35-39 8.5 % 40-44 10.5 % 45-49 11.5 % 50-54 13.5 % 55-59 14.25 % 60-65 15 % 65-70 0 %

**0 % 4.0 % 5.5 % 6.5 % 7.5 % 8.5 % 8.5 % 9.25 % 10.0 % 0 %**

<sup>2</sup> Die Zusatzbeiträge betragen in Prozenten des versicherten Jahreslohns: Alter Sparbeitrag Arbeitgeber Sparbeitrag Arbeitnehmer (Jahre) 18-65 1.5 %

**1.5 %**

Art. 2 Dieser Beschluss tritt auf den 1. Januar 2014 in Kraft. Er ersetzt den Standeskommissionsbeschluss über die Versicherungskasse vom 16. Dezember 2008 (StKB VKV Vorsorgereglement).
