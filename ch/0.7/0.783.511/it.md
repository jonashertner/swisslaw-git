# Regolamento generale dell’Unione postale universale****

Concluso a Doha l’11 ottobre 2012[^t-1]

Ratificato dalla Svizzera con strumento depositato il 17 ottobre 2018

Entrato in vigore per la Svizzera con effetto retroattivo dal 1° gennaio 2014

(Stato 1° luglio 2019)

[^t-1]: Il teso non è pubblicato nella RU. Il testo originale francese può essere consultato sul sito Internet dell'Unione postale universale (http://www.upu.int/fr.html &gt; Ressources &gt; Publications &gt; Banque de données terminologique «TERMPOST» &gt; Accès à «TERMPOST») o può essere richiesto al DATEC, PostReg, Palazzo federale Nord, 3003 Berna (RU 2019 **2005** 2099).
